Dokümantasyon

POST /api/developer/v1/video-info

Verilen bir YouTube, TikTok veya Instagram bağlantısındaki medyanın meta verilerini, başlığını ve format bilgilerini yüksek hızda çözer.

cURL Örneği 
curl -X POST https://filewizardio.com/api/developer/v1/video-info \
  -H "X-API-Key: fw_live_sizin_anahtariniz_buraya" \
  -F "url=https://www.youtube.com/watch?v=ornek"

Örnek Yanıt (JSON)

{
  "success": true,
  "data": {
    "title": "Örnek Video Başlığı",
    "duration": "03:45",
    "uploader": "Kanal Adı",
    "platform": "youtube"
  },
  "developer_message": "İşlem başarılı. Aylık kotanızdan 1 kredi düşüldü."
}
